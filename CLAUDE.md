Fonts are self-hosted in `public/fonts/` (woff2, latin subset, downloaded from Google Fonts on 2026-10-29) and preloaded in `Base.astro`: Hanken Grotesk variable 400 to 800 for everything, plus Lora italic 500 for one accent phrase per headline (Instrument Serif was tried first and read too much like script). Wrap that phrase in `<em>` inside an `h1` or `h2` and it renders serif italic green automatically. `font-display: block` plus an `html.fonts-pending` hold (body hidden until `document.fonts.ready`, max 1s) means text never paints in a fallback font and reflows. Don't go back to the Google Fonts stylesheet: loading it async caused a visible font swap on every page load. The old site used niveau-grotesk (Adobe Fonts).

## Design direction (decided 2026-10-29)

"Cinematic dark hero, light body." The homepage opens on a full-height ink hero with film grain (`.grain`), a cursor-following green glow, the tilted project-photo stack, and a transparent nav (white logo) that turns solid white once the hero is scrolled past (`nav.nav-dark`, set in `Nav.astro` for `/`). The hero's bottom corners are rounded into the light body. Everything you have to read sits on white or mist. CTA bands and the footer go back to ink with grain.

Type is a fluid scale (`--fs-display`, `--fs-h1`, `--fs-h2` in `:root`) so headlines are huge on desktop and still fit a 390px phone. Body stays 17px / 1.65. `text-wrap: balance` on headings, `pretty` on paragraphs. Eyebrows are small caps with a green dot.

Homepage sections, in order: hero → client logo marquee → results bento (`.bento`, counters including the real 15,450,000 organic impressions figure from the old site, a photo tile and a serif pull quote) → numbered editorial service rows that reveal a photo on hover (`.service-list`) → pinned work reel → us vs other agencies → review marquees → CTA band. Inner pages keep the light `page-head` pattern with a serif accent in the h1.

Logos: `public/images/logo-dark.png` and `logo-white.png` (1257x474 PNGs from the old site; the tree mark is the first 370px).

Favicons: white tree mark on a navy tile. `favicon.ico` (16/32/48), `favicon-32.png`, `favicon-96.png`, `apple-touch-icon.png` (180, square). Regenerate with `node scripts/favicons.mjs`.

Share images: `public/og-default.png` (1200x630, navy, logo + hero headline + UCS work photo) is the default `og:image`. Case studies use `public/images/work/<slug>/share.jpg`, a 1200x630 JPG made from the cover by `node scripts/share-jpgs.mjs` (Facebook and LinkedIn don't render WebP); that script also re-encodes any cover over 300KB. Run it after adding a case study. Regenerate the default with `node scripts/og-image.mjs` after changing the hero headline.

Markdown images in case studies get `width`/`height` (and lazy loading) at build time from `src/plugins/rehype-img-size.mjs`, so they don't shift the page as they load.

## Motion

All animation lives in `src/scripts/motion.ts` (GSAP 3 with ScrollTrigger and SplitText, bundled from npm), with its CSS in the "MOTION LAYER" block at the end of `global.css`.

- Headlines rise word by word (SplitText, masked lines); `.reveal` blocks fade up in staggered batches; the hero photo stack drops in, drifts at different speeds on scroll, and leans toward the cursor with a trailing green glow.
- Homepage: client logo marquee, stats count up ("Millions" scrambles in), a pinned sideways-scrolling work reel with a counter (desktop 900px+; a swipeable carousel below that), two review marquees running opposite ways, us-vs-them list where their side gets struck through, and a big outlined marquee over every CTA band that skews with scroll speed.
- Site-wide: green scroll progress bar, nav hides on scroll down and returns on scroll up, case study covers wipe open, cross-page fade/slide (CSS `@view-transition`).
- Mouse only (`hover: hover` and `pointer: fine`): cursor follower that grows into "View"/"Play" over work and videos, magnetic buttons, 3D tilt plus a cursor spotlight on cards.
- Safety: `html.motion` (set by an inline script in `Base.astro`) is what hides elements before they animate. It is never set with reduced motion, and it is removed after 3s if `motion.ts` hasn't started, so content can't get stuck invisible. Reduced motion gets a fully static page with marquees turned into plain wrapped rows.
- To add motion to a new block, give it `class="reveal"`. New `h2`s inside `.sec-title`/`.sec-head` animate automatically.
- Testing gotcha: when the Claude app window isn't in the foreground, its browser pane runs almost no animation frames, so everything looks stuck mid-entrance. In `npm run dev`, `window.gsap` is exposed: run `gsap.ticker.lagSmoothing(0); setInterval(() => gsap.ticker.tick(), 16)` in the page to drive it.

## Cutover day

Do these in one go, so the new site replaces WordPress the minute it goes live:

1. Every old URL in the inventory above has a new page or a 301 in `public/_redirects`, and `FORM_URL` is set (send a test message).
2. Set `STAGING = false` in `src/config.ts` (turns on indexing, analytics, and the sitemap line). Build, commit, push to `master`.
3. In Sevalla, add `integritygrove.com` and `www.integritygrove.com` as domains on the static site.
4. Point DNS at Sevalla using the records it gives you. Leave email records (MX, SPF, DKIM) alone.
5. Check the live domain: pages load, a made-up URL shows the custom 404, old URLs 301, `robots.txt` lists the sitemap, page source shows `index, follow`.
6. Submit `sitemap-index.xml` in Google Search Console.
