Marketing agency site for Integrity Grove (Aaron Jarnagin, Strategy Lead & Partner, and Isaac Jarnagin). Social media account management, websites and digital assets, photo and video production. Being rebuilt in October 2026 from a WordPress/Divi site into a custom static site, same setup as the aaronjarnagin and aarongoesoutdoors sites.

## Tech stack & hosting

- Framework: Astro (static site generator), compiled to plain HTML/CSS at build time. Same system as aaronjarnagin and aarongoesoutdoors.
- Hosting: Sevalla (Kinsta static hosting) is the intended host, auto-deploys on git push. Build command `npm run build`, publish dir `dist`, root `.`, Node LTS.
- Staging: https://integritygrove-l3fdz.kinsta.page (Sevalla, auto-deploys from `master`). Kept private: `STAGING = true` in `src/config.ts` makes every page `noindex, nofollow`, turns analytics off, and drops the sitemap line from `robots.txt` (generated by `src/pages/robots.txt.ts`). Crawling stays allowed on purpose so Google can see the noindex.
- Live domain: https://integritygrove.com stays on the old WordPress site until cutover. Nothing on staging should be public or indexed before then.
- Local folder: `C:\Users\aaron\Documents\integritygrove`
- Repo: GitHub `aaronjarnagin/integritygrove`, branch `master` (not `main`), private.
- `public/_redirects`: Sevalla does NOT auto-serve `404.html`, so the catch-all `/* /404.html 404` rule there is what makes the custom 404 work. Keep it last.

## Site structure

All old WordPress URLs were kept, so most links need no redirect.

- `src/config.ts`: `STAGING` switch, `BOOK_URL` (Google Calendar discovery-call booking, the main call to action site-wide), `EMAIL`.
- `src/layouts/Base.astro`: head/SEO/meta/OG/schema, Google tag, reveal animation, nav scroll border, mobile menu, YouTube click-to-load. `src/layouts/Prose.astro` wraps Markdown pages.
- `src/data/site.ts`: reviews (shared by home, services, discovery call), client logos, filter labels.
- Components: `Nav`, `Footer`, `WorkCard`, `Reviews`, `CtaBand` (navy "book a call" band, id `contact`), `YouTube`.
- `src/pages/index.astro`: hero with work-photo stack, client logo strip, stats band, services, 6 latest case studies, us vs other agencies, reviews, CTA.
- `src/pages/[slug].astro`: case study template, served at the site ROOT (`/<slug>/`) to keep the old post URLs. Cover, Markdown body, video grid, 3 related, CTA.
- `src/pages/work/`: all case studies with filter chips (`?f=websites|social|photo|video`).
- `social-media-account-management/` and `websites-digital-assets/`: service pages with packages and pricing from the old site ($1,500/mo social, $1,750 websites).
- `about/` (team and history timeline), `contact/` (book a call or email, no form yet), `discovery-call/` (ad landing page aimed at Ames businesses), `privacy-policy/` and `terms-conditions/` (Markdown, text copied verbatim from the old site), `404.astro`.
- Retired with 301s in `public/_redirects`: `/thank-you/`, `/social-media-quiz/`, `/links/`, `/category/*`, `/page/*`, `/author/*`, `/feed/`.

## Case studies

One Markdown file per project in `src/content/work/` (schema in `src/content.config.ts`). The filename is the URL slug. Frontmatter: `title`, `client`, `location`, `date` (newest first everywhere), `summary` (first sentence becomes the card text, first 155 characters the meta description), `filters` (websites, social, photo, video), `cover`, `coverAlt`, optional `videos` (YouTube IDs) and `draft`. Images live in `public/images/work/<slug>/` as WebP.

## Cutover day

Do these in one go, so the new site replaces WordPress the minute it goes live:

1. Every old URL in the inventory above has a new page or a 301 in `public/_redirects`.
2. Set `STAGING = false` in `src/config.ts` (turns on indexing, analytics, and the sitemap line). Build, commit, push to `master`.
3. In Sevalla, add `integritygrove.com` and `www.integritygrove.com` as domains on the static site.
4. Point DNS at Sevalla using the records it gives you. Leave email records (MX, SPF, DKIM) alone.
5. Check the live domain: pages load, a made-up URL shows the custom 404, old URLs 301, `robots.txt` lists the sitemap, page source shows `index, follow`.
6. Submit `sitemap-index.xml` in Google Search Console.
